# Machine Learning for Ecological Time Series (METR01)

Machine Learning for Ecological Time Series is an applied R course teaching ecologists how to
analyse, model, and predict ecological time series data. This course combines time series analysis
theory with machine learning approaches, equipping participants with practical R skills to handle
real ecological datasets. Classical time series models are covered alongside modern machine learning
algorithms, culminating in a complete end-to-end ML pipeline for time series.

By the end of the course, participants should:

- Understand the fundamental structure of time series data and basic handling techniques;
- Understand time series operations such as differentiation and decomposition;
- Understand classical time series models, including AR, ARIMA, VAR, SARIMA, ARCH, and GARCH;
- Understand the concepts behind time series reconstruction and decomposition and their connection with ML;
- Understand the definition and types of machine learning (supervised, unsupervised, reinforcement, semi-supervised);
- Understand fundamental learning algorithms and their applications in ecology;
- Have the confidence to preprocess time series data for machine learning models using R;
- Have the confidence to implement a complete machine learning pipeline for ecological time series;

## Day 1: A Short Course in R Basics (9:30–17:30)

This day provides participants with the foundational R skills required for working with time series
and machine learning. It is designed for beginners or those needing a refresher in R programming.

- **Session 1 – R Essentials (3:00:00):** This section focuses on R syntax, variables, data types,
  conditionals (`if`, `else`, `elif`), loops (`for`, `while`), and writing reusable code using
  functions.

- **Session 2 – Data Structures and File Handling in R (3:00:00):** This section emphasises
  understanding data structures (e.g., vectors, data frames, lists) and handling files by
  reading/writing data (e.g., CSVs) for manipulation and analysis.

Live Q and A from 19:00–20:30

---

## Day 2: Fundamentals of Time Series Analysis I (9:30–17:30)

This day focuses on the theoretical foundations of time series analysis, detailing the main aspects.

- **Session 3 – The Time Series Setting (3:00:00):** This section covers the fundamental structure
  of time series data, basic time series handling techniques, and an introduction to various time
  series operations, such as differentiation, decomposition, and others.

- **Session 4 – Classical Models in Time Series Analysis I (3:00:00):** This section examines
  classical time series analysis models, including Autoregressive (AR), Autoregressive Integrated
  Moving Average (ARIMA) models, and their variants with exogenous time series.

Live Q and A from 19:00–20:30

---

## Day 3: Fundamentals of Time Series Analysis II (9:30–17:30)

This day focuses on the practical and theoretical foundations of more advanced methods of time
series analysis.

- **Session 5 – Classical Models in Time Series Analysis II (3:00:00):** Introduces more advanced
  models, such as Vector Autoregressive (VAR) Models, Seasonal Autoregressive Integrated Moving
  Average (SARIMA), Autoregressive Conditional Heteroskedasticity (ARCH), and Generalised
  Autoregressive Conditional Heteroskedasticity (GARCH) models.

- **Session 6 – Time Series Reconstruction and Decomposition (3:00:00):** Provides a detailed
  explanation of more advanced methods used for time series reconstruction and decomposition and
  their connection with ML.

Live Q and A from 19:00–20:30

---

## Day 4: Fundamentals of Machine Learning for Time Series (9:30–17:30)

- **Session 7 – Introduction to Machine Learning (3:00:00):** This section covers the definition
  of machine learning, types of learning (supervised, unsupervised, reinforcement,
  semi-supervised), applications of machine learning to time series, and an overview of R
  libraries for ML.

- **Session 8 – Fundamental Learning Algorithms (3:00:00):** This section examines the available
  learning algorithms and their applications, accompanied by practical examples in ecology.

Live Q and A from 19:00–20:30

---

## Day 5: The Machine Learning Pipeline for Time Series (9:30–17:30)

Participants will learn about the end-to-end workflow of a typical machine learning project applied
to ecological time series.

- **Session 9 – Preprocessing Data and Selecting Algorithms (3:00:00):** This section focuses on
  preprocessing techniques to prepare time series data for machine learning models. An
  entomological example illustrating the application of machine learning to ecology will be used.

- **Session 10 – The Complete Machine Learning Pipeline for Time Series (3:00:00):** Covers the
  end-to-end machine learning workflow, including the use of preprocessed series data and the
  creation of pipelines to automate critical aspects of the workflow.

Live Q and A from 19:00–20:30
